# CopyCo

CopyCo 是一款轻量、原生的 macOS 菜单栏剪贴板历史工具。它以辅助应用方式运行，只显示在菜单栏中，不会在 Dock 里新增图标。

[English](README.md)

[下载最新版本](https://github.com/xiaochengfu/CopyCo/releases/latest)

## 功能

- **键盘优先：** 按 `⌥⌘C` 打开历史记录，输入内容搜索，用方向键选择条目，按 Return 粘贴。
- **原生且轻量：** 使用 Swift 和 macOS 系统框架构建，没有第三方运行时依赖。
- **本地优先的隐私保护：** 剪贴板历史只保存在你的 Mac 上，不会上传任何数据。
- **实用的隐私控制：** 可以暂停记录、排除来源应用、设置保留上限，或随时清空历史记录。
- **支持多种剪贴板内容：** 在设定的大小限制内保存纯文本、RTF/HTML 富文本、图片、文件 URL 和网页 URL。

## 下载安装

从 [GitHub Releases](https://github.com/xiaochengfu/CopyCo/releases/latest) 下载 `CopyCo.app.zip`，然后：

1. 解压下载的 ZIP 文件。
2. 将 `CopyCo.app` 移动到 `/Applications` 或你习惯存放应用的位置。
3. 在 Finder 中打开 CopyCo。

CopyCo 当前需要 **macOS 15 或更高版本**。下载版采用 ad-hoc 签名，且未经 Apple 公证。首次打开时，macOS 可能显示安全确认。如果系统阻止启动，可以在 Finder 中按住 Control 点击应用，选择 **打开**；也可以在被阻止后前往 **系统设置 → 隐私与安全性 → 仍要打开**。

当前下载版面向 Apple Silicon（`arm64`），本次发布不支持 Intel Mac。

## 首次启动

1. 在菜单栏中找到 **CopyCo**，打开 **设置**。
2. 选择 **打开辅助功能设置**。
3. 在 **隐私与安全性 → 辅助功能** 中启用 CopyCo。
4. 返回 CopyCo，选择 **刷新权限状态**。
5. 在其他应用中复制内容，然后按 `⌥⌘C` 打开历史面板。

辅助功能权限只用于让 CopyCo 直接粘贴到其他应用。未授予该权限时，选择条目仍会将内容恢复到系统剪贴板，CopyCo 会提示你手动按 `⌘V` 粘贴。

## 日常使用

| 操作 | 使用方式 |
| --- | --- |
| 打开历史记录 | 按 `⌥⌘C`，或点击菜单栏图标。 |
| 搜索 | 打开历史面板后直接输入。 |
| 粘贴条目 | 选中条目后按 Return。 |
| 移动选择 | 使用向上、向下方向键。 |
| 关闭面板 | 按 Escape。 |
| 删除条目 | 选中条目后按 Forward Delete。 |
| 暂停记录 | 在菜单或设置中选择 **暂停记录**。 |
| 清空历史 | 需要删除全部已保存条目时选择 **清空历史记录**。 |
| 排除应用 | 在设置中配置排除的来源应用。 |

如果目标位置没有文本光标、目标应用不可用，或无法直接粘贴，CopyCo 会先准备好选中的内容，并提示你点击目标位置。随后再次按 `⌥⌘C`，或使用 `⌘V`，即可完成操作。

当全局快捷键已被其他应用占用时，可以使用菜单栏图标打开历史面板。

## 隐私与存储

CopyCo 将剪贴板历史保存在本机：

```text
~/Library/Application Support/CopyCo/History
```

该目录包含 `index.json` 元数据文件和本地二进制内容文件。CopyCo 没有服务器连接，也不会上传剪贴板数据。默认保留上限为：

- 50 条记录
- 总计 500 MiB
- 单次剪贴板变化 25 MiB

你可以在设置中将上限提高到 500 条记录和总计 1,024 MiB。达到上限后，最早的条目会被自动移除。

CopyCo 会忽略隐藏和临时剪贴板、已配置排除的应用，以及已知密码管理器来源。跳过这类内容时会显示简短状态提示，避免被误认为“复制失败”。但剪贴板历史仍应视为本地敏感数据：复制机密信息前请暂停记录，并在需要时使用 **清空历史记录**。

### 密码框与 Secure Event Input

当焦点位于密码输入框时，macOS 会启用 **Secure Event Input（安全事件输入）**。在此模式下，系统不会向其他应用投递 Carbon 全局快捷键，因此 `⌥⌘C`（或你自定义的快捷键）无法唤起 CopyCo。这是系统安全机制，CopyCo 不会关闭 Secure Event Input。

Secure Event Input 生效期间，CopyCo 会在菜单栏状态中说明限制。请改用菜单栏的 **显示历史记录**，或离开密码框后再按快捷键。将历史条目粘贴到密码框仍需要辅助功能权限；即使辅助功能不提供选区信息，CopyCo 也会把安全文本框识别为可粘贴目标。

支持保存的内容包括纯文本、RTF/HTML 富文本、图片、文件 URL 和网页 URL。不支持的类型，以及超过单项大小上限的内容会被跳过。如果日后启动时发现已保存内容缺失或损坏，CopyCo 会丢弃该条目，而不会尝试粘贴不完整的数据。

## 从源码构建

CopyCo 需要 macOS 15 或更高版本，以及 Xcode 或 Command Line Tools 提供的 Swift 工具链。

运行测试：

```bash
swift test
```

构建应用：

```bash
scripts/build-app.sh
open build/CopyCo.app
```

日常本地调试可以使用启动脚本。它会构建 Release 版本、打开应用，并输出首次运行检查清单：

```bash
scripts/run-local.sh
```

打包脚本会生成 `build/CopyCo.app`，移除二进制中的本地构建路径，验证公开发布包，并默认应用不包含个人身份的 ad-hoc 签名，供本地使用。
